publish to GitHub

1. Click download updated data.js above.

2. Open your website's GitHub repository and choose Add file → Upload files.

3. Upload the new data.js, replacing the existing version, and commit your change. GitHub Pages will deploy the updated website.

This editor is intentionally simple: it doesn't need your GitHub password or an access token. Each browser has its own draft until you export and publish it.
